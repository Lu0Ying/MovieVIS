# 电影评论可视化 · 一页计划

**选题**：个人类选题，缘起是“一个影迷想搞清电影口碑好在哪、差在哪”；个人背景只作切入视角，数据主体是影评语料，不引入个人观影记录。

## 做什么图

组合方案，明确不用柱状图、饼图、横向堆叠条：

- **顶部导航**：口碑—争议散点气泡。X=平均星级，Y=星级标准差，大小=评论量，颜色=正面率。
- **主视图**：电影 × 类别气泡矩阵。横轴 C0—C8，纵轴电影按星级排序，面积=提及量，颜色=类别正面率，带色标。
- **流向层**：类别 → 正/中/负桑基图。流宽=提及量，看满意/不满意流向哪个维度。
- **详情层**：雷达图（剧情/表演/视听/音乐/导演/主题）、正负词云、星级蜂群点图、评论列表。

## 数据从哪来

- 主数据：Kaggle DMSC v2，28 部电影、约 213 万条中文短评、405.61 MB、CC0；Kaggle API 下载。
- 元数据：Kaggle 豆瓣电影数据集，2,065 部，含类型、年份、导演、海报；28 部手工映射兜底。
- 备选：OpenBayes dmsc_v2 镜像；textdata 1000w（10,269 部/1,031 万条/1.35 GB，百度网盘）。爬虫仅作小批量补充，不作为主方案。

## 维度与规模（课程硬指标）

- 8 个维度：电影身份、评分、评论文本、评论类别、情感倾向、时间、热度、类型/年份/导演。
- 数据量：语料 213 万条，分析抽样 2 万条，gold 300 条，均远超 5,000。
- 聚合：`movie_agg` 28 行，`category_agg` 28×9 行，直接供气泡矩阵与桑基使用。

## 评论怎么分类

- 9 类多标签，单条最多 3 个：C0 整体、C1 剧情、C2 表演、C3 视听、C4 音乐、C5 导演、C6 主题、C7 场外、C8 其他。
- 情感双轨：星级弱标签（1—2 负、3 中、4—5 正）用于气泡颜色；词典/模型文本情感用于类别内比较。
- 落地：关键词规则 L0 先跑全量 → 人工标 300 条 gold（100 条双标，kappa≥0.60）→ 有余力再上 TF-IDF/LLM 校验。
- 过滤：去重、广告水印、非中文、无信息短文本、想看标记；剧透只标记折叠，不删除。

## 交互与手绘

- 交互：悬停 tooltip、点击气泡锁定、框选、类型/年份/情感筛选、矩阵单元格下钻、桑基流过滤、剧透开关、重置。
- 手绘：4 轮记录——3 种布局发散 → 组内批注评审 → 选定方案细化 → 手绘与成品对照；拍照/扫描入 Word 正文，禁止 AI 生成冒充手绘。

## 三个以上深度洞察（候选）

1. **高口碑不等于低争议**：散点右上象限 + 框选，找出“高分高争议”电影。
2. **差评集中在剧情而非表演**：矩阵 C1 颜色偏负、C2 偏正；点击 C1 单元格看评论。
3. **争议由结局/改编/删减触发**：桑基 C1→负面 + 词云高频词 + 评论列表验证。
4. **类型决定争议容忍度**：按类型筛选散点，看文艺片与商业片落在哪些象限。

每条按“现象—证据—解释—反例”写，证据必须指到具体图、交互和样本量。

## 4 人怎么分

- A：第 1 步数据下载 + 统稿；第 1/2/8/9 章。
- B：第 2—3 步数据理解与过滤；第 3/4 章。
- C：第 4 步清洗、分词、情感、分类、标注与聚合；第 5 章。
- D：第 5—7 步组合映射、交互、手绘设计过程；第 6/7 章。
